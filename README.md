# ChronoNote 时光墨历

> **全景时空日历 · 多主题卡片流 · 双栏实时 Markdown · 本地优先数字工作台**

ChronoNote 是专为思考者、读书爱好者与终身学习者打造的**双轨制（时间轴 × 主题流）**知识与日记工作台。打破传统日历软件“一天只能写一篇流水账”的束缚，让每一次灵感、每一本好书的心得、每一段岁月的温度都能在时间长河中优雅沉淀。

---

## ✨ 核心特性一览

### 1. 📅 12个月年度全景与年轮切换 (Yearly Compass)
- **快捷年轮切换**：支持任意年份（`2024` $\leftrightarrow$ `2026` $\leftrightarrow$ `2027`）自由穿梭。
- **12月极简微缩宫格**：3×4 全景展开，直观俯瞰全年的思考痕迹。
- **动态主题色谱与精力热力图**：日期格微光呈现当天记录的主题分布（紫色=读书、绿色=日记、黄色=灵感...）。

### 2. 📚 单日多主题卡片流 (Multi-Topic Day Workspace)
- **多篇独立并存**：同一天内可记录无限条独立随笔（读完一本书写书评，傍晚写日记，深夜记录灵感）。
- **主题池与自定义**：`读书思考`、`岁月日记`、`灵感闪念`、`复盘精进`、`光影留声`、`深度工作`，支持随时新建自定义主题与专属色彩。
- **主题透视库 (Topic Lens)**：打破单日孤岛，将一年中所有“读书思考”卡片串联为专属倒序时间轴。

### 3. 🕰️ “那年今日” 时光胶囊 (On This Day)
- 当停留在某一日期时，系统自动检索往年同月同日（如 2025年、2024年的同一天）的随笔与感悟。
- 浮现温暖的跨时空对话卡片，点击即可翻看往年今天的思考与生活印记。

### 4. 🔍 全局聚焦检索 (Spotlight Search · `Ctrl + K`)
- 全局快捷键 `Ctrl + K` 呼出极简搜索浮窗。
- 支持按标题、正文关键词、标签、主题或日期毫秒级全文检索，键盘上下键即选即看。

### 5. ✍️ 智能模板与深度 Markdown 工作台
- **主题专属结构化模板**：
  - 点击 `+ 读书思考` 自动填入包含《书名》、作者、核心模型、金句与行动启发的专属架构。
  - 点击 `+ 复盘精进` 自动带入得失反思与下一步行动；支持在设置中自定义各主题模板。
- **双向平滑同步滚动 (Sync Scroll)**：左侧编辑与右侧书本级排版预览精准对齐。
- **截图直接粘贴 (`Ctrl + V`)**：剪贴板截图或图片直接粘贴进 Markdown，自动转存并渲染。
- **双向时空链接 (Wiki-Links)**：输入 `[[2026-10-08]]` 或 `[[书名]]` 自动渲染为可点击跳转的时空胶囊。
- **全套快捷键**：粗体 (`Ctrl+B`)、斜体 (`Ctrl+I`)、删除线 (`Ctrl+Shift+X`)、标题 1~3 (`Ctrl+1~3`)、引用 (`Ctrl+Q`)、代码块 (`Ctrl+Shift+C`)、待办清单 (`Ctrl+T`)、即时保存 (`Ctrl+S`)、三视图切换 (`Ctrl+P`)。

### 6. 🎧 沉浸打字音效与白噪音 (Zen Soundscape)
- 内置程序化机械打字机音效，输入时有清脆解压的微触感反馈。
- 可选窗外细雨声 (Rain) 与壁炉柴火声 (Hearth Fire) 白噪音，营造独处心流环境。

### 7. 🖼️ 画廊漫游模式 (Story / Card Gallery View)
- 顶栏切换至【画廊漫游】，以大号拍立得卡片形式展示随笔，可用键盘 $\leftarrow$ $\rightarrow$ 像翻阅个人文集相册一样沉浸漫游。

### 8. 📁 界面自定义本地数据目录 (Custom Local Vault)
- 齿轮【设置】中支持随时浏览并绑定本地任意磁盘文件夹（如坚果云、OneDrive 同步盘或 Obsidian 库）。
- 支持一键将全库随笔同步导出为规范的 `年/月/日期_标题.md` 本地文件。

### 9. 🔒 私密日记密码锁 (Privacy Lock)
- 设置中可开启 PIN 码保护，支持顶栏一键锁屏与启动验证，保护个人隐秘思绪。

### 10. 📖 年度回忆录装订成书排版与打印 (Annual Memoir Export)
- 自动为全年的随笔生成带封面、作者署名、目录、月度分卷章节的高清排版长卷。
- 1-click 支持 `Ctrl + P` 打印或直接另存为精美排版 PDF。

### 11. ✨ AI 智能复盘小结 (AI Digest & Model Auto-Fetch)
- 支持本地 **Ollama**（私有免翻墙免Token费）与 **DeepSeek / OpenAI** 兼容端点。
- **“一键获取模型列表”**：自动连接本地 Ollama 服务或云端 API，下拉列表一键载入所有本地已有模型。
- **一键提炼**：自动汇总最近一周、本月或全年的思考与生活温度，提炼系统性复盘长文，支持一键沉淀为新的复盘笔记。

### 12. ⚡ 全局闪念输入窗 (Quick Capture HUD · `Alt + 1`)
- **系统级热键直达**：按下 `Alt + 1` 随时呼出极简 HUD 悬浮框，无需打断当前工作流。
- **瞬时沉淀**：快速记录灵感、选择主题、心境与标签，`Ctrl + Enter` 一秒存入今日时间线。

### 13. 🌌 时空星云关系图谱 (Constellation Knowledge Graph)
- **深空天体交互**：以 HTML5 Canvas 呈现知识银河，主题为引力核心，随笔为发光星宿。
- **Wiki-links 发光光弧**：自动解析 `[[链接]]` 并绘制知识链。
- **时空演化推演**：支持 1~12 月时空切片滑块与自动播放，直观回放一年中知识网络的成长轨迹。

### 14. 🧠 读书笔记间隔记忆闪卡 (SRS Spaced Repetition · SM-2)
- 自动提取读书笔记中的书摘、金句与核心模型为记忆翻转卡片。
- 基于经典 SuperMemo SM-2 间隔复习算法（`1`生疏、`2`良好、`3`熟练），科学对抗遗忘曲线。

### 15. ⏱️ 禅意番茄钟与心流足迹打卡 (Zen Pomodoro & Focus Logger)
- 自定义专注时长（15m / 25m / 45m / 60m / 自由步进微调）。
- 程序化白噪音（雨声、壁炉）与 528Hz 藏音颂钵铜钟禅音。
- 专注完成后一键将时间段与心得打卡记录到今日笔记。

### 16. 🎨 365 像素年历与年度情绪晴雨表 (Year in Pixels & Mood Radar)
- 12个月 × 31天像素全景织锦，五维心境（💡灵感、☕平和、🔥激情、🌿舒适、🌧️沉思）着色。
- 点击任意像素方格一键直达该日工作区，附带月度心流能量起伏曲线。

### 17. 🔍 全文倒排搜索索引 (High Performance Inverted Search Index)
- 中英文汉字单字与二元连词（Bi-gram）倒排索引，毫秒级响应。
- 支持 `tag:标签`、`topic:主题`、`mood:心境`、`"精确短语"` 等结构化搜索语法与高亮上下文摘要。

### 18. ✨ AI Markdown 排版与审美优化顾问 (AI Format Beautifier & Diff Review)
- 双模引擎（本地排版规则 + Ollama/OpenAI 大模型）。
- 智能诊断标题层级、中英文盘古间距、代码块与表格规范，提供双栏 Diff 对比，由用户自主决定是否一键采纳。

### 19. 🎨 四套大师级视觉主题与窗口记忆
- 🌙 **深空墨夜 (Obsidian Night)**
- 📜 **暖白纸韵 (Warm Paper)**
- 🌲 **晨雾青峦 (Misty Forest)**
- 🍂 **落日琥珀 (Sunset Amber)**
- **窗口大小记忆**：自动记忆调节后的窗口宽度、高度与位置，下次启动无需重复调节。

## 🚀 启动与运行

在项目目录 `c:\projects\chrononote\` 中双击对应脚本即可（已严格配置 UTF-8 编码，杜绝中文乱码）：

*   **`启动应用-桌面客户端.bat`**：直接唤起原生独立桌面应用窗口。
*   **`启动应用-浏览器调试.bat`**：在浏览器打开 `http://localhost:5173` 进行网页端调试。
